# Security Policy

## Public toolkit content

This repository contains public educational resources and does not contain the private HonorlyAI application source code, production configuration, credentials, student data, or district records.

Please use a public issue for:

- a broken link;
- an unclear template instruction;
- a factual correction;
- an accessibility issue in the public Markdown resources.

## Product security and privacy reports

Do **not** open a public issue for a suspected vulnerability involving HonorlyAI's product, infrastructure, authentication, access controls, student or educator data, district deployments, or private repositories.

Submit the report through https://honorlyai.com/contact and clearly label it **Security report**. Include only the minimum information needed to reproduce the issue. Do not access, retain, or share data that does not belong to you.

## Safe research expectations

- Test only systems and accounts you are authorized to test.
- Do not disrupt service, degrade availability, or attempt persistence.
- Do not use social engineering, credential stuffing, phishing, or denial-of-service techniques.
- Stop immediately if testing exposes personal information or another user's data.
- Allow a reasonable remediation window before any disclosure.

This file does not create a bug bounty, promise payment, waive legal rights, or authorize testing beyond the permissions expressly granted to you.
