# Support

## Questions about the public toolkit

Open a GitHub issue for:

- template corrections;
- broken links;
- unclear instructions;
- accessibility improvements;
- resource requests;
- implementation examples that contain no private information.

## Questions about HonorlyAI

For district pilots, product questions, privacy review, or partnerships, use https://honorlyai.com/contact.

- About HonorlyAI: https://honorlyai.com/about
- K-12 AI resources: https://honorlyai.com/resources
- Privacy Policy: https://honorlyai.com/privacy
- Data Protection Addendum: https://honorlyai.com/dpa

## Security and privacy vulnerabilities

Do not open a public issue. Follow [SECURITY.md](SECURITY.md).

This public repository cannot provide legal advice or district-specific compliance determinations.
