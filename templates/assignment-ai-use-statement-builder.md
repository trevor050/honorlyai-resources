## Step 1: identify the intellectual work

Complete the sentence:

> The purpose of this assignment is to show that the student can `[ANALYZE / EXPLAIN / CALCULATE / DESIGN / ARGUE / REVISE / RESEARCH / CREATE / OTHER]` without outsourcing `[THE SKILL BEING ASSESSED]`.

Check the parts of the process that matter to the grade:

- [ ] interpreting the prompt;
- [ ] generating ideas;
- [ ] selecting evidence;
- [ ] finding and evaluating sources;
- [ ] organizing reasoning;
- [ ] drafting language or code;
- [ ] solving calculations;
- [ ] revising based on feedback;
- [ ] editing grammar, syntax, or presentation;
- [ ] explaining and defending decisions;
- [ ] applying the skill independently to a new problem.

## Step 2: select the AI-use level

Choose one level, then customize the statement below.

### Level 1: independent work

Use when the task is intended to show unaided performance of the assessed skill.

**Default statement:**

> Do not use generative AI to plan, solve, draft, revise, translate, summarize, or check this assignment. You may use the accommodations and non-generative tools specifically approved by your teacher or plan. Ask before using a feature if you are unsure whether it generates or rewrites content.

### Level 2: AI tutoring only

Use when students may receive explanations or practice but must create the submitted work independently.

**Default statement:**

> You may use `[APPROVED TOOL]` to ask for explanations, examples, practice questions, or clarification about the concept. Do not ask the tool to produce, rewrite, solve, or complete any part of the response you submit. Include the short disclosure described below.

### Level 3: AI feedback and revision support

Use when students must create a first draft or solution before receiving AI critique.

**Default statement:**

> Complete and save your own first draft before using AI. You may use `[APPROVED TOOL]` to request feedback on `[CLARITY / REASONING / ORGANIZATION / GRAMMAR / TEST CASES / OTHER]`. Do not ask the tool to replace the full draft or generate the final response. Submit the original version, final version, and disclosure.

### Level 4: AI collaboration is part of the assignment

Use when prompting, evaluating, verifying, and transforming AI output are part of the learning objective.

**Default statement:**

> AI use is part of this assignment. Follow the required workflow, preserve the prompts and outputs identified below, verify factual and source claims, label material AI contributions, and be prepared to explain every submitted decision. You remain responsible for accuracy, attribution, and the final work.

## Step 3: list allowed actions

Use concrete verbs. Check and adapt every allowed action.

Students may use the approved tool to:

- [ ] ask for an explanation of a concept;
- [ ] request another example;
- [ ] generate practice questions not included in the submitted work;
- [ ] receive hints without a final answer;
- [ ] brainstorm questions or possible directions;
- [ ] generate search terms;
- [ ] compare organizational approaches;
- [ ] receive rubric-based feedback after a first draft;
- [ ] identify unclear reasoning;
- [ ] suggest test cases for student-written code;
- [ ] check spelling or grammar without rewriting full passages;
- [ ] translate directions or support language access as approved;
- [ ] generate material that will be explicitly critiqued in the assignment;
- [ ] other: `[INSERT]`.

## Step 4: list prohibited actions

Students may not use AI to:

- [ ] generate the final answer;
- [ ] write a paragraph, essay, lab conclusion, reflection, or discussion response submitted as the student's own;
- [ ] solve a problem whose solution process is being assessed;
- [ ] rewrite an entire draft or section;
- [ ] fabricate sources, quotations, data, interviews, citations, or experiences;
- [ ] summarize a text the student is required to read independently;
- [ ] create code or calculations the student cannot explain;
- [ ] enter private, identifying, confidential, or restricted information;
- [ ] use an unapproved personal account or service;
- [ ] conceal or misrepresent AI assistance;
- [ ] other: `[INSERT]`.

## Step 7: select the disclosure requirement

### Minimal disclosure

> I used `[TOOL]` for `[PURPOSE]`. I did not include generated text or answers in the submitted work.

### Feedback disclosure

> I completed my first draft before using `[TOOL]`. I asked for feedback about `[CRITERIA]`. I accepted these suggestions: `[INSERT]`. I rejected these suggestions: `[INSERT]`. I verified `[FACTS / SOURCES / CALCULATIONS]` by `[METHOD]`.

### Collaboration disclosure

Require some or all of:

- [ ] tool and model or feature name;
- [ ] date of use;
- [ ] selected prompts;
- [ ] selected outputs;
- [ ] original draft or attempt;
- [ ] final draft;
- [ ] fact and source verification record;
- [ ] explanation of accepted and rejected suggestions;
- [ ] reflection on what the student contributed;
- [ ] formal citation where required by the assigned style.

## Step 8: state independent responsibility

Select and adapt:

> You must be able to explain every claim, step, source, calculation, design choice, and sentence in the submitted work.

> You may be asked to complete a short in-class or oral verification task using the same skill without AI.

> AI output may be incorrect, incomplete, biased, or fabricated. You are responsible for checking it against course materials and retrievable sources.

> A disclosure does not make prohibited assistance acceptable. It provides evidence about assistance that the assignment permits.

## Step 9: explain the review process

## Teacher quality check

Before publishing, confirm:

- [ ] the learning objective is named;
- [ ] allowed actions use concrete verbs;
- [ ] prohibited actions use concrete verbs;
- [ ] embedded features such as translation, grammar rewriting, autocomplete, image generation, and code completion are addressed where relevant;
- [ ] approved tools and accounts are identified;
- [ ] data limits are stated;
- [ ] accommodations and alternatives are preserved;
- [ ] disclosure matches the amount of permitted use;
- [ ] students know what they must be able to explain independently;
- [ ] the review process does not treat detector output as proof;
- [ ] the statement is visible before students begin.
